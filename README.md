# Daleth Sales Hub Professional V1.1

CRM comercial interno da Daleth AC.

## Rodar localmente

```bash
cd ~/Downloads/daleth-sales-hub-professional-v1-1
npm install --legacy-peer-deps
npm run dev
```

Abrir: http://localhost:5173
